================================================================================
                        FLUXO DE EXECUÇÃO DO JOGO
================================================================================

Main.java
   │
   └─► Jogo.java
         │
         ├─► inicializarJogo()
         │     ├─► Cria Jogador
         │     └─► Cria 3 Pistoleiros (ArrayList)
         │
         ├─► criarInterface()
         │     └─► Mostra tela inicial com história
         │
         └─► enfrentarProximoPistoleiro()  [LOOP para cada pistoleiro]
               │
               ├─► FaseNavegacao.iniciar()
               │     ├─► Mostra caminho (10 segundos)
               │     ├─► Coleta input do jogador
               │     └─► Verifica se acertou
               │
               └─► FaseDuelo.iniciar()
                     ├─► Aguarda sinal aleatório
                     ├─► Detecta teclas (ESPAÇO + ENTER)
                     ├─► Timer do pistoleiro
                     ├─► Determina vencedor
                     └─► Se vitória: adiciona arma ao inventário

================================================================================
                        COMO COMPILAR E EXECUTAR
================================================================================

WINDOWS:
--------
1. Abra o Prompt de Comando
2. Navegue até a pasta do projeto:
   > cd C:\Users\joaol\OneDrive\Desktop\velhooeste
3. Execute:
   > compilar.bat
4. Depois:
   > executar.bat

OU MANUALMENTE:
   > javac -d bin -encoding UTF-8 src/*.java
   > java -cp bin Main


LINUX / MAC:
------------
1. Abra o Terminal
2. Navegue até a pasta do projeto
3. Dê permissão de execução:
   $ chmod +x compilar.sh executar.sh
4. Execute:
   $ ./compilar.sh
5. Depois:
   $ ./executar.sh

OU MANUALMENTE:
   $ javac -d bin -encoding UTF-8 src/*.java
   $ java -cp bin Main

================================================================================
                            GAMEPLAY RESUMIDO
================================================================================

1. INÍCIO
   ├─ Jogador insere seu nome
   └─ História é apresentada

2. PARA CADA PISTOLEIRO (3 no total):
   │
   ├─ FASE 1: NAVEGAÇÃO
   │  ├─ Sistema mostra caminho (ex: Frente → Esquerda → Direita)
   │  ├─ Jogador tem 10 segundos para memorizar
   │  ├─ Jogador digita o caminho
   │  └─ Se errar: pode tentar novamente ou desistir
   │
   └─ FASE 2: DUELO
      ├─ Espera sinal "ATIRE!"
      ├─ Jogador pressiona ESPAÇO + ENTER
      ├─ Se for mais rápido que o pistoleiro: VENCE
      ├─ Se for mais lento: PERDE (pode tentar de novo)
      └─ Vitória: ganha arma do pistoleiro

3. FIM
   └─ Após derrotar os 3 pistoleiros: JOGO COMPLETO! ✨
